# Lanka Travellers – Travel Agency Website

A simple responsive website for **Lanka Travellers**, a fictional Sri Lankan travel agency, made with **React** (Vite + React Router).
There is no database – the contact form just shows a thank you message.

## Pages

- **Home** – logo, hero section, company introduction, featured packages, call-to-action buttons
- **Packages** – 4 tour packages with name, destination, duration, price, description, places/activities, image and a Book Now button
- **About Us** – company introduction, vision and mission, why choose us, services, team and company information
- **Contact Us** – phone, email, address, contact form, social media links and Google Map
- **Photo Credits** – the photos are from Wikimedia Commons

## How to run

```bash
npm install      # first time only
npm run dev      # open http://localhost:5173
npm run build    # creates the dist/ folder for hosting
```

Package details are in `src/data/packages.js` and contact details are in `src/data/company.js`.
